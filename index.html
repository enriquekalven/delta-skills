Prelude: Qualification, MVP Alignment & Access Clearance (Before Week 1)

Do not start the 12-week clock until the use case passes the Data Yardstick and Ford Cloud Admin signs Developer Clearance.

Week 0 · Gate 0
workshop-intake Toolbox #01 & #10 docs/WORKSHOP_INTAKE.md

Qualifies Ford's candidate use case (`Idea → Good → Ready`) across the 6-dimension Data Yardstick (`Available / Usable / Quality`).

Prompt to Your Coding Agent
Use workshop-intake to analyze the Ford discovery notes in raw-notes/. Score the 33 Starter Questions and the 6-Dimension Data Yardstick, list open blockers to ask Ford SMEs tomorrow, and write docs/WORKSHOP_INTAKE.md.
create-delta-ucc Toolbox #04 & #10 docs/USE_CASE_CANVAS.md

Locks the 1-page MVP contract (`Problem, Target Users, In-Scope MVP, Out-of-Scope, Success Metrics, Key Dependencies`).

Prompt to Your Coding Agent
Use create-delta-ucc on docs/WORKSHOP_INTAKE.md to generate the 4-Tab Use Case Canvas and the 1-Page Use Case Alignment Summary for Ford at docs/USE_CASE_CANVAS.md.
tdl-field-guide + specification-engineer Toolbox #11, #12, #14 STATE.md

Sets up the 7-tab Program Tracker structure (`Timeline, Use Cases, Staffing, Use Case RAID, Program RAID, Meetings, OOO`) and the cloud clearance checklist.

Prompt to Your Coding Agent
Use tdl-field-guide to initialize STATE.md for the Ford engagement at phase: 0 (Prelude) with dual RAID logs, and use specification-engineer Part III to generate the Developer Access & Golden Dataset Clearance checklist for Ford's cloud admin.
Gate 0 Exit Criteria: Ford Cloud Admin signs Developer Clearance + 50-item Golden Dataset reachable in sandbox → set phase: 1 in STATE.md.

Phase 1: Foundations — Ethnography, Baseline, PRD & Tech Spec (Weeks 1–2)

Shadow Ford SMEs, freeze the 50-sample statistical baseline, lock the 8-section Agentic PRD, and write the 4-part Technical Spec.

Weeks 1–2 · Gate 1
business-process-redesign + cuj-architect Toolbox #02 & #03 docs/CUJ_MAP.md + docs/to_be_designs.md

Turns SME shadowing notes into task decomposition tables, L1/L2/L3 autonomy boundaries, HITL gates, and the scored 4-tab CUJ matrix.

Prompt to Your Coding Agent
Use business-process-redesign and cuj-architect on our Ford shadowing notes to produce docs/as_is_report.md, docs/to_be_designs.md, docs/human_agent_roles.md, and docs/CUJ_MAP.md (scoring each AI touchpoint with 0.6*Value + 0.4*Feasibility).
synthetic-baseline-protocol docs/baseline_kpis.json

Computes mean, median, P90 handling time, 95% confidence intervals, error rate, escalation rate, and annual baseline cost across 50 historical Ford items.

Prompt to Your Coding Agent
Use product-md to write docs/PRD.md for Ford from docs/CUJ_MAP.md and docs/baseline_kpis.json following go/delta-prd-template.

Compares Tier 1 (Gemini Enterprise), Tier 2 (ADK on Agent Runtime), and Tier 3 (ADK on Cloud Run/GKE) with verified GA/Preview stages, then writes Parts I–IV of `go/delta-squad-agent-specs`.

First use gcp-agent-architecture-advisor on docs/PRD.md to select Tier 1, 2, or 3, verify current GCP launch stages, and write docs/ARCHITECTURE_RECOMMENDATION.md. Then use specification-engineer to write the 4-part Agent Technical Specification at docs/TDD.md.
stitch-design Toolbox #13 & #15 docs/STITCH_PROTOTYPE.md

Gate 1 Exit Criteria (End of Week 2): Ford Sponsor + TDL sign off on docs/PRD.md, docs/TDD.md, and docs/baseline_kpis.json → set phase: 2 in STATE.md.

Weeks 3–10 · Sprints 1–4 · Gate 2
claude-agent-harness + google-agents-cli src/ + tests/ + .harness/last_run_report.json

Iterates against `docs/PRD.md` and `docs/TDD.md` until all acceptance unit tests and linters exit `0`.

Terminal Command
python3 ~/.gemini/config/plugins/tdl-user-guide/ai-coding/claude-agent-harness/scripts/call_opus_model_garden.py \
  --project "$GOOGLE_CLOUD_PROJECT" \
  --workspace . \
  --goal "Implement the Ford ADK agent and tools per docs/TDD.md" \
  --spec docs/PRD.md --spec docs/TDD.md \
  --verify "python3 -m unittest discover -s tests -p 'test_*.py'"

Prompt to Your Coding Agent
Use tdl-field-guide to generate docs/DEMO_FRAME_UP.md mapping all committed features in docs/PRD.md across Demo 1, Demo 2, and Demo 3, and update STATE.md for our current sprint.
agent-load-testing Toolbox #16 docs/LOAD_TEST_REPORT.md

Calculates `1 + Qt + (Qt × Cq) + 1` calls per turn, sizes Vertex AI RPM/TPM quotas at 5x peak, and generates the Locust SSE load test report.

Terminal Command
python3 ~/.gemini/config/plugins/tdl-user-guide/delivery/agent-load-testing/scripts/calculate_agent_quotas.py \
  --qt 6 --cq 4 --tokens-per-call 20000 --peak-turns-per-min 10 --safety-multiplier 5.0
agent-eval-statistical-auditing Toolbox #17 & #18 docs/EVAL_AUDIT_REPORT.md

Audits your LLM Judge against Ford SMEs across Pipeline 1 (`Pearson r`, `ICC(2,1)`, `Krippendorff α`, `QWK`), Pipeline 2 (`Bias`, `Compression Ratio`), and Pipeline 3 (`Flip Rate`, `Entropy`).

Terminal Command
python3 ~/.gemini/config/plugins/tdl-user-guide/delivery/agent-eval-statistical-auditing/scripts/audit_llm_judge.py \
  --input ~/.gemini/config/plugins/tdl-user-guide/delivery/agent-eval-statistical-auditing/examples/fixtures/calibrated_judge.json
Gate 2 Exit Criteria (End of Week 10): Demo 3 accepted + Vertex quotas provisioned at 5x peak + Judge AUA certified (`PASS`) → set phase: 3 in STATE.md.

Phase 3: Final Read-Out, Measured ROI & Closeout (Weeks 11–12)

Compare measured production telemetry against the frozen Week 1 baseline, deliver the Executive Closeout Deck, and run the FDE Blameless Retro.

Weeks 11–12 · Gate 3
ai-value-sizing docs/VALUE_SIZING.md

Computes 3-year NPV, ROI %, payback months, and net annual value across Base, Bull, and Bear scenarios.

Terminal Command
python3 ~/.gemini/config/plugins/tdl-user-guide/ai-value-sizing/scripts/calculate_roi.py \
  --tam-units 50000 --sam-share 0.80 --adoption-rate 0.50 --tech-compat 0.90 \
  --hours-saved 0.55 --hourly-rate 68.0 --capex 200000 --annual-opex 55000 \
  --vcr 0.60 --scdf 0.85 --wacc 0.10
tdl-field-guide Toolbox #08 & #09 STATE.md + Closeout & Retro

Generates the Closeout Deck (`The Challenge | The Vision | The Experience | The Architecture | The Value`), finalizes the `docs/TDD.md` runbook, and harvests reusable patterns.

Prompt to Your Coding Agent
Use tdl-field-guide to compile our Ford Executive Closeout Deck outline from docs/VALUE_SIZING.md and docs/PRD.md, close out the dual RAID logs in STATE.md, and draft our FDE Blameless Retrospective notes.
Gate 3 Exit Criteria (Week 12 Close): Agent live in Ford production with monitoring + Executive Read-Out delivered with measured KPIs + Runbook signed off.
