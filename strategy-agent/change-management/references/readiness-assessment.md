# Change Readiness Assessment

Assess organizational readiness for change across six critical dimensions.

## Change Scope Clarification

| Element | Assessment |
|---------|------------|
| **Change type** | Technology / Process / Structure / Culture / Strategic Pivot / Combination |
| **Change scale** | Team-level (< 50 people) / Department (50-500) / Organization-wide (500+) |
| **Change depth** | Incremental (modify current ways) / Transformational (new ways entirely) |
| **Timeline** | Months to full adoption; months to stabilize |
| **Reversibility** | Reversible / Hard to reverse / Irreversible (market forces it) |

## Organizational Readiness Scorecard

Score each dimension 1-10 (10 = ready, 1 = blocked):

### EXECUTIVE ALIGNMENT
Do leaders agree this change is necessary? Are they committed to resource it and model it? Are incentive systems aligned?

**Scoring:**
- 8-10: Strong executive alignment; committed to investment
- 5-7: Moderate agreement; some skepticism
- 1-4: Significant disagreement; weak commitment

**Mitigation if low:** Get executive alignment before proceeding. Single dissenting leader can block adoption.

### CHANGE CAPACITY
Can the org staff the transformation (dedicated PMO, change leads, training teams) while running the business? Historical success with change? Burnout risk?

**Scoring:**
- 8-10: Capacity exists; proven change track record
- 5-7: Capacity available but stretched
- 1-4: Insufficient capacity; org is burned out

**Mitigation if low:** Reduce scope, extend timeline, or hire external change support.

### TECHNICAL READINESS
Do systems, tools, infrastructure exist to enable the change? Gaps? Timeline to close?

**Scoring:**
- 8-10: Systems exist; minimal enablement work needed
- 5-7: Some systems exist; some build required
- 1-4: Significant gaps; major infrastructure investment needed

**Mitigation if low:** Build systems in parallel with change; account for technical timeline.

### CULTURE RECEPTIVITY
How open is the org to change? Historical change success/failure? Rate of innovation adoption? Trust in leadership?

**Scoring:**
- 8-10: Culture actively embraces change; history of success
- 5-7: Neutral culture; mixed change history
- 1-4: Change-averse culture; failed changes; low trust

**Mitigation if low:** Invest in building trust; start with quick wins; transparent communication.

### CAPABILITY MATURITY
Can people do the new ways? Do skill gaps exist? How deep? Timeline to upskill?

**Scoring:**
- 8-10: People have skills; minimal training needed
- 5-7: Some skills exist; training required
- 1-4: Major skill gaps; deep training investment needed

**Mitigation if low:** Invest in training; consider hiring; plan for slow ramp-up.

### CLEAR CHANGE LOGIC
Do people understand why this change is necessary? Is the case compelling, data-driven? Clarity on: problem being solved, solution approach, expected outcomes?

**Scoring:**
- 8-10: Compelling case; clear problem and solution
- 5-7: Rationale exists; some questions remain
- 1-4: Unclear logic; unconvinced of necessity

**Mitigation if low:** Invest in building change narrative; make the case data-driven; address concerns directly.

## Using Readiness Assessment

**If readiness ≥ 70%:** Proceed with standard change plan.

**If readiness 50-70%:** Proceed but build contingencies. Address readiness gaps in parallel:
- Weak executive alignment → Extra executive steering meetings
- Low change capacity → Hire external support
- Capability gaps → Invest in training upfront
- Culture receptivity low → Start with quick wins to build trust

**If readiness < 50%:** Do not proceed. First, address readiness gaps:
- Build executive alignment (executive workshops, data review)
- Build change capacity (hire PMO, change leaders)
- Close capability gaps (training program)
- Shift culture (quick wins, transparent communication)

Timeline to readiness: 4-12 weeks typical.
