# Capability Framework & Gap Analysis

Map required capabilities, maturity levels, and development plans.

## Capability Maturity Scale

Use a 1-10 scale or these stages:
- 1-3: Immature (we struggle with this)
- 4-6: Developing (we're building this)
- 7-8: Mature (we do this well)
- 9-10: Leading (we're best-in-class)

## Capability Framework Template

### For Each Core Capability:

```
CAPABILITY: [Customer Success at Scale]
  Why Critical: [Coherent Action X requires ability to deliver at X scale]
  Current Maturity: [Immature / Developing / Mature]
  Target Maturity: [Mature by end of Year 2]
  Owner: [VP Customer Success]

  Sub-capabilities:
    ├─ Onboarding Excellence (Maturity: 4/10 → Target: 9/10)
    ├─ Technical Support (Maturity: 7/10 → Target: 9/10)
    ├─ Expansion Sales (Maturity: 3/10 → Target: 8/10)
    └─ Customer Health Monitoring (Maturity: 2/10 → Target: 8/10)

  Gap Analysis:
    ├─ People: Need 3 new CS engineers; need training on system X
    ├─ Process: Need 90-day onboarding playbook
    ├─ Tools: Need customer health dashboard
    └─ Budget: $200K for people; $50K for tools

  Timeline: 6 months to Developing; 18 months to Mature
```

## Gap Closure Approach

For each gap, determine the approach:

**People Gap:**
- Hiring: Roles needed, timeline, search strategy
- Training: Skills to develop, training approach, timeline
- Reorganization: Teams to restructure, reporting changes

**Process Gap:**
- Document: Which processes need design/redesign?
- Training: How will people learn new processes?
- Reinforcement: How will you lock in new behaviors?

**Tools Gap:**
- Current state: What tools exist?
- Target state: What capabilities do you need?
- Implementation: Timeline, training, adoption plan

**Budget Gap:**
- One-time costs: Tools, training infrastructure, hiring search
- Recurring costs: Salaries, subscriptions, maintenance
- Timeline: When is each investment needed?

## Validation Questions

For each capability:

1. Does this capability trace back to a Coherent Action?
2. Is the current maturity score realistic? (Validate with functional leader)
3. Is the target maturity achievable in the timeline? (Benchmark against similar orgs)
4. Is the gap analysis complete? (People, process, tools, budget?)
5. Are sub-capabilities the right level of detail? (Specific enough to action)
6. Is the owner accountable for closing the gap? (Do they have authority and resources?)
