# McKinsey 7-S Model (Cross-Check)

Validate operating model across seven dimensions. Design MUST align across all dimensions.

## The Seven Dimensions

| Dimension | Definition | Operating Model Implication |
|-----------|-----------|---------------------------|
| **Strategy** | The coherent kernel from Rumelt | Your operating model must enable every coherent action |
| **Structure** | Reporting, hierarchy, org units | Direct enabler of strategy; must trace to Coherent Actions |
| **Systems** | Processes, workflows, procedures | Codify how work happens; enable scale |
| **Style** | Leadership culture, decision norms | Sets tone for accountability, risk-taking, collaboration |
| **Staff** | Talent, skills, capability | Must match structure and execute processes |
| **Skills** | Core competencies, capabilities | Builds competitive advantage; enables strategy |
| **Shared Values** | Mission, culture, identity | Glue; what binds org when structure changes |

## Alignment Check

If any two dimensions contradict, the model breaks.

**Example failure:** Strategy says "move fast" but Structure is hierarchical and Processes require 5-level approvals → System failure.

## Validation Process

1. Map each dimension to your target model
2. Identify dependencies between dimensions
3. Flag any contradictions
4. Iterate until all seven dimensions reinforce each other
5. Test the model against Coherent Actions—can the structure and systems actually execute them?
