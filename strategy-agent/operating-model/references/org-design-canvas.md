# Operating Model Canvas

Every operating model design maps six interconnected dimensions:

## OPERATING MODEL CANVAS

### 1. STRUCTURE
- Reporting hierarchy (who reports to whom)
- Primary org unit (P&L, function, customer segment, geography?)
- Cross-functional coordination (teams that work together)
- Span of control ratios (how many reports per manager?)

### 2. GOVERNANCE
- Decision Rights (who decides X, Y, Z?)
- Escalation Paths (when do we escalate? to whom?)
- Review Cadence (monthly planning? weekly ops reviews? quarterly strategy?)
- Approval Authority (spend limits, hiring, strategic decisions)

### 3. PROCESSES
- Planning (budgeting, OKR setting, strategic planning cycle)
- Operations (weekly ops reviews, daily standups, incident response)
- People (hiring, onboarding, performance, development)
- Customer (escalation, contracts, expansion decision)
- Finance (expense approval, forecasting, capital allocation)

### 4. CAPABILITIES
- Core capabilities (what must we excel at?)
- Capability owners (who builds/maintains each?)
- Capability maturity (where are we now? target?)
- Capability gaps (what do we need to build? hire? buy?)

### 5. CULTURE & MINDSET
- Decision-making style (consensus vs. leader calls?)
- Risk tolerance (innovation vs. risk-aversion?)
- Accountability (who gets rewarded for what?)
- Learning (how do we improve continuously?)

### 6. SYSTEMS & TOOLS
- HCM (HR, payroll, org management)
- Planning tools (budgeting, OKR tracking, forecasting)
- Collaboration tools (communication, file management)
- Operational tools (CRM, project management, analytics)

## Using the Canvas

When assessing current state or designing target state, fill in all six dimensions to ensure comprehensive coverage. This prevents siloed thinking and ensures all aspects of the organization support the strategy.
