# Galbraith Star Model (Capability Design)

Design capability layer using five interrelated components that must all reinforce strategy.

## The Five-Point Star

```
                    STRATEGY
                        ↑
        ┌───────────────┼───────────────┐
        ↓               ↓               ↓
   STRUCTURE      PROCESSES       REWARDS
        ↓               ↓               ↓
        └───────────────┼───────────────┘
                        ↓
                   PEOPLE & CULTURE
```

## Component Definitions

### STRATEGY
What are we trying to do? Must derive from Rumelt kernel and coherent actions.

### STRUCTURE
How do we organize to do it? Reporting lines, hierarchy, org units that enable strategy.

### PROCESSES
How do we coordinate across structure? Workflows, decision forums, communication cadence.

### REWARDS
What behaviors do we incentivize? Compensation, promotion, recognition aligned to strategy.

### PEOPLE & CULTURE
What culture and capability do we need? Skills, mindsets, values that enable new ways of working.

## Integration Rule

All five must reinforce each other. If one is misaligned, capability doesn't scale.

**Example:** If you redesign structure to be flat but keep hierarchical decision processes and reward only individual achievement (not collaboration), the organization won't adopt flat decision-making.

## Using the Model

1. Start with strategy → define required capabilities
2. Design structure to enable those capabilities
3. Build processes that enforce the capability requirements
4. Align rewards to reinforce new behaviors
5. Invest in people development and cultural change
6. Validate that all five reinforce each other
