# Test Sequence Roadmap (12-Month Template)

Sequence your hypothesis tests to minimize cost and maximize learning.

## HYPOTHESIS TEST SEQUENCE (12 Months)

### QUARTER 1 — STRATEGIC FOUNDATION
Test the biggest risks first. Reduce your biggest uncertainties.

```
TEST 1 (Weeks 1-2): Market size & customer need
  Hypothesis: Enterprise market for [product] is $[X]M+
  Methodology: Anecdote + Survey
  Evidence: 10 customer interviews + 50-person survey
  Cost: $8K
  Success metric: 60%+ of respondents agree [problem] is acute
  Confidence gain: 30% → 55%
  Owner: [Name]

TEST 2 (Weeks 3-6): Product-market fit
  Hypothesis: Customers will [core action] with MVP lacking [feature]
  Methodology: MVP with 30-50 users
  Evidence: Functional MVP, retention metric
  Cost: $30K
  Success metric: 60%+ Day-7 retention
  Confidence gain: 45% → 75%
  Owner: [Name]

GATE DECISION (Week 7): Proceed to Q2?
  ├─ If both tests succeed (confidence 70%+): YES → proceed to Q2
  ├─ If Test 1 fails: Pivot to different segment, retry Test 1
  └─ If Test 2 fails: Redesign product, retry Test 2
```

### QUARTER 2 — GO-TO-MARKET VALIDATION
Once product is validated, prove you can execute unit economics.

```
TEST 3 (Weeks 8-12): Pricing and messaging
  Hypothesis: Customers perceive value at $[price]; elasticity [range]
  Methodology: Pricing experiment + messaging test
  Evidence: Experiment with 100+ prospects
  Cost: $12K
  Success metric: 40%+ conversion at target price
  Confidence gain: 50% → 70%
  Owner: [Name]

TEST 4 (Weeks 13-16): Channel and CAC
  Hypothesis: [Channel] acquires customers at $[CAC target]
  Methodology: Pilot campaign
  Evidence: 50+ customer conversions
  Cost: $40K
  Success metric: CAC ≤ $[target]; payback ≤ 12 months
  Confidence gain: 50% → 75%
  Owner: [Name]

GATE DECISION (Week 17): Ready to scale?
  ├─ If unit economics validated (confidence 75%+): YES → prepare scale
  ├─ If Test 3 fails: Price test, segment test, or value prop redesign
  └─ If Test 4 fails: Channel pivot or GTM design refresh
```

### QUARTER 3-4 — EXPANSION VALIDATION
Reduce secondary risks. Prove long-term viability.

```
TEST 5 (Weeks 18-22): Retention hypothesis
  Hypothesis: [Cohort] retains at [%], driven by [core behavior]
  Methodology: Cohort analysis + customer interviews
  Success metric: [Retention %] at [month]
  Cost: $10K

TEST 6 (Weeks 23-26): Competitive response
  Hypothesis: Competitive response won't erode unit economics
  Methodology: Competitive testing + win-loss analysis
  Success metric: Our positioning vs. competitor hold market share
  Cost: $15K

TEST 7 (Weeks 27-30): Market expansion
  Hypothesis: Secondary market / segment will adopt at similar unit economics
  Methodology: Pilot in secondary segment
  Success metric: CAC and LTV hold in new segment
  Cost: $50K
```

## Prioritization Formula

For each hypothesis, calculate priority score:

```
Priority Score = (Risk × Impact) / Cost

Risk (1-10):
  10 = Strategy fails if hypothesis is wrong
  5 = Strategy materially changes
  1 = Minor impact

Impact (1-10):
  10 = Unlocks 5+ downstream hypotheses
  5 = Unlocks 1-2 downstream hypotheses
  1 = Standalone hypothesis

Cost ($K):
  50 = Expensive (multi-week pilot)
  20 = Medium
  5 = Cheap (survey or interviews)

Example:
  Hypothesis: "Market exists"
    Risk: 10, Impact: 10, Cost: $8K
    Priority: (10 × 10) / 8 = 12.5 ← TEST FIRST

  Hypothesis: "Dark mode improves engagement"
    Risk: 2, Impact: 1, Cost: $5K
    Priority: (2 × 1) / 5 = 0.4 ← TEST LAST
```

## Success Criteria & Go/Kill Decisions

```
Milestone 1 (Week 7 / End Q1):
  Gate: ≥2 of 2 tests succeed (confidence ≥70%)
  If Pass: Proceed to Q2 GTM validation
  If Fail: Redesign hypothesis or pivot

Milestone 2 (Week 17 / End Q2):
  Gate: Unit economics proven (CAC ≤ target; LTV/CAC ≥ 3:1; Confidence ≥75%)
  If Pass: Plan scale; scale test to 1000+ customers
  If Fail: Kill hypothesis or redesign GTM

Milestone 3 (Month 12 / End Q3-Q4):
  Gate: Validated at scale (1000+ customers, confidence ≥85%)
  If Pass: Go to market; scale to full target market
  If Fail: Refine positioning; test in adjacent segment
```
