# Standard Report Section Structure & Critique Framework

## 8-Section Report Template

Every ATLAS report uses exactly 8 sections in this order. Adapt titles to the specific engagement:

| # | Section | Primary Skill | Content Focus |
|---|---------|---------------|---------------|
| 01 | Executive Summary | Strategy Partner | Verdict, 3-5 key findings, recommendation, investment required, timeline |
| 02 | Strategic Diagnosis | Strategy Partner + Market Intelligence | Situation analysis, competitive landscape, key forces, crux identification |
| 03 | The Crux Decision | Rumelt Forge | The singular strategic challenge, strategy kernel, coherent actions |
| 04 | Product/Solution Architecture | Product Innovation | Product design, feature prioritization, technical approach, MVP definition |
| 05 | Technology & Build | Technology & Digital | Tech stack, build vs buy, integration, timeline, team composition |
| 06 | Financial Model | Financial Strategy | Revenue model, unit economics, investment, payback, sensitivity analysis |
| 07 | Go-to-Market | GTM Strategy | Launch strategy, customer acquisition, pricing, partnerships |
| 08 | Risk Assessment | All Skills (adversarial) | Devil's Advocate, Bear Case, kill conditions, make-or-break assumption |

Between each section, include a **bridge paragraph** that connects the conclusion of the previous section to the premise of the next.

## Stage 2: Expert Critique Panels

### Design Panel Prompt

```
You are a panel of 3 world-class design experts critiquing this ATLAS strategy report:
1. Julie Zhuo (ex-VP Design, Meta) — Product design, information hierarchy
2. Mike Monteiro (Design consultant) — Typography, layout, visual weight
3. Jony Ive (ex-Apple CDO) — Premium feel, restraint, emotional design

Rate current state 1-10. For each issue provide:
- What's wrong (specific element)
- Design principle violated
- Exact fix (CSS values, HTML changes)

Focus: Typography hierarchy, color sophistication, whitespace rhythm, sidebar quality,
data visualization, top bar/hero premium feel, micro-interactions, overall boardroom test.

Would this impress McKinsey's design team and Google's UX team? Be brutally honest.
```

### Strategy Panel Prompt

```
You are a panel of 3 elite strategy consultants reviewing this report:
1. McKinsey Senior Partner — Structure, MECE logic, executive readability
2. BCG Managing Director — Insight depth, competitive differentiation
3. Bain Partner — Actionability, financial rigor, implementation clarity

Rate current state 1-10. For each issue:
- What's missing or weak
- What a $50K engagement would include
- Specific content/structure fix

Focus: Narrative arc (does it build to a decision?), executive summary strength,
assumption visibility, decision governance, actionability of recommendations,
financial model credibility, risk assessment rigor.
```

## Applying Critiques

After both panels complete:
1. Synthesize fixes into unified improvement list
2. Prioritize by impact
3. Apply ALL fixes while preserving 100% of original data points

**Verification checklist (run after Stage 3):**
- [ ] All financial figures match original analysis
- [ ] All skill attributions present
- [ ] Devil's Advocate and Bear Case content preserved
- [ ] Bridge paragraphs connect all 8 sections
- [ ] Make-or-break assumption prominently displayed
- [ ] No duplicate ATLAS logos (only in topbar)
- [ ] All micro-interactions functional
- [ ] Scrollspy working
- [ ] Progress bar working
