# Scenario Analysis for ATLAS Report Template

## Four-Scenario Framework for Report Quality

This framework describes how report quality and output adjust across probability-weighted scenarios.

### UPSIDE (20% probability)
All skills executed flawlessly, data complete, critique loop transforms to 10x output.

**Conditions:**
- All 8+ skills provided complete structured output
- No data gaps requiring fallback
- Critique panelists generate 20+ actionable improvements
- Zero data mismatches between skills

**Assumptions:**
- Stage 3 output achieves 9.5/10 quality score
- Zero data inconsistencies
- Report is McKinsey-equivalent quality

**Output adjustments:**
- Implement all critique fixes without compromise
- Add premium micro-interactions and animations
- Elevate visual hierarchy maximally
- Polish typography and spacing to premium standards

**Quality level:** Boardroom-ready, publication-quality output indistinguishable from $100K+ consulting engagement

---

### BASE CASE (50% probability)
Skills complete, minor data gaps resolved, critique delivers standard improvements.

**Conditions:**
- Most skills provide complete structured output
- Few gaps requiring fallback protocol
- Critique generates 10-15 improvements
- 1-2 data reconciliations needed

**Assumptions:**
- Stage 3 output achieves 8.5/10 quality score
- Data reconciliations succeed without major rework
- All sections complete and coherent

**Output adjustments:**
- Implement priority critique fixes
- Address data gaps with fallback protocol
- Standard elevation workflow
- Basic polish applied uniformly

**Quality level:** Executive-ready, professional consulting-quality output, board-presentation ready

---

### DOWNSIDE (20% probability)
Incomplete skill outputs, significant data gaps, critique reveals structural issues.

**Conditions:**
- 2+ skills have incomplete data
- Multiple fallback protocols needed
- Critique finds 20+ issues indicating structural problems
- Significant rework needed

**Assumptions:**
- Stage 3 output achieves 7/10 quality score
- Significant content rework required
- Narrative coherence issues discovered late

**Output adjustments:**
- Trigger error handling protocol
- Request skill re-runs for missing data
- Delay report publication
- Flag as DRAFT pending content improvements

**Quality level:** Functional but sub-par; requires rework before C-suite release

---

### DISRUPTIVE (10% probability)
Skill conflict on core finding, contradictory recommendations, output unusable.

**Conditions:**
- 2+ skills have contradictory recommendations on strategy
- Data conflicts unresolvable
- Report internally inconsistent
- Core findings in conflict

**Assumptions:**
- Report quality score <6/10
- Report unusable for decision-making without resolution
- Fundamental disagreement on direction

**Output adjustments:**
- Trigger CONFLICT-RESOLUTION.md protocol
- Coordinate skill re-analysis
- Likely delay publication significantly
- Document conflict in report footer with mitigation notes

**Quality level:** Report blocked pending conflict resolution; unsuitable for publication

---

## Scenario Transition Triggers

Use these signals to assess which scenario applies and adjust timeline/expectations:

**Upside indicators:**
- All 8+ skills with structured output
- Confidence levels HIGH across all domains
- Zero conflicts detected in skill outputs
- Data quality passes pre-flight at 100%
- Critique panel initial scoring ≥8/10

**Downside indicators:**
- 2+ skills missing data
- Confidence MEDIUM or LOW in multiple findings
- 1-2 minor conflicts requiring resolution
- Data quality 70-85% on pre-flight check
- Critique panel initial scoring 6-7/10

**Disruptive indicators:**
- 2+ fundamental conflicts between skills on core strategy
- Core finding contradictions discovered
- Data quality <70% on pre-flight
- Conflicting recommendations on strategic direction
- Critique panel initial scoring <6/10
