# ATLAS Speed Modes

ATLAS supports three execution modes, each balancing timeline against quality. Select based on engagement urgency and client expectations.

## Quick Strike (4 hours)

**Description:** Stage 1 + Stage 3 report (skip expert critique loop).

**When to use:**
- Time-sensitive executive briefing
- Internal strategy review
- Proof-of-concept presentation

**Process:**
- Generate Stage 1 report from skill outputs
- Apply basic design polish (correct typography, alignment, spacing per ATLAS system)
- Ship

**Output:** Complete 8-section HTML report, all data intact, basic visual polish

**Quality:** 7/10 (functionally complete, visually basic, no expert refinement)

**Trade-off:** Savings 1.5 days of timeline. Sacrifice design and strategy polish. Narrative may have rough edges.

**Timing:** Stage 1 generation (2h) + design polish (2h) = 4h total

---

## Standard (2 days)

**Description:** Full 3-stage pipeline (Stage 1 → Stage 2 critique → Stage 3 elevation).

**When to use:**
- Most client engagements
- Board presentations
- Strategic decisions with moderate timeline

**Process:**
- Generate Stage 1 report
- Run parallel Design + Strategy expert panels (both critique independently, score 1-10, produce 10-20 fixes each)
- Synthesize fixes + apply all BLOCKER + PRIORITY fixes
- Re-verify data
- Ship Stage 3

**Output:** Polished, boardroom-ready HTML report with expert-refined design and strategy narrative

**Quality:** 8.5/10 (professional consulting-quality, McKinsey-equivalent, ready for C-suite)

**Trade-off:** 2-day timeline. All critiques applied. Narrative polished. Design premium.

**Timing:** Stage 1 (2h) + Stage 2 panels parallel (4h) + Stage 3 fixes (4h) + verification (2h) = 12h across 2 days

---

## Deep Dive (3-4 days)

**Description:** Full pipeline with iterative meta-critique.

**When to use:**
- High-stakes decisions
- External board presentations
- Publication-quality deliverables
- Competitive bids

**Process:**
- Generate Stage 1 report
- Run Stage 2 critique panels
- Apply fixes for Stage 3
- Re-run critique on Stage 3 output (meta-critique: does the fix quality pass the same rigor?)
- Iterate until both panels rate Stage 3 as 9+/10
- Final verification

**Output:** Premium, publication-quality HTML report indistinguishable from high-end management consulting deliverables

**Quality:** 9.5/10 (publication-ready, won't need rework, defensive to external scrutiny)

**Trade-off:** 3-4 day timeline. Meta-critique iteration adds 1 day. Highest quality possible.

**Timing:** Stage 1 (2h) + Stage 2 panels (4h) + Stage 3 fixes (4h) + meta-critique (4h) + Stage 3.5 fixes (2h) + final polish (2h) = 18h across 3-4 days

---

## Mode Selection Logic

Select mode based on timeline and quality requirements:

- If timeline <12 hours AND acceptable quality is 7/10 → Quick Strike
- If timeline 1-2 days AND acceptable quality is 8-9/10 → Standard
- If timeline 3+ days AND acceptable quality is 9.5/10 required → Deep Dive
- If conflicting skill outputs exist → Minimum Standard mode (Deep Dive if P0 strategic conflict)
